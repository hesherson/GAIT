GAIT 1.8.0-alpha9 validation

HEMTT 1.21.0 build: PASS, with BI Tools staging enabled.
Config version 1.8.0.9; 16 compiled SQF files; 2 PBOs.
Nonblocking style advisories remain. No Arma runtime was available.

All 18 actual-helper SQF-VM suites: PASS, zero diagnostics.
Recorded source hashes match the final source. Portable evidence is in
VALIDATION_RESULTS.json. The runner compiles each suite from current source;
engine boundary mocks do not simulate animation rendering or physical travel.

Movement coverage includes:
- current release coefficient/velocity/time snapshots, captured vegetation
  attenuation removal, stale snapshot rejection and repeated partial releases;
- both render/main release processing orders, single-consumption tracking,
  fresh Shift presses and W re-presses while Shift stays held;
- early brace releases below the ordinary target skip deceleration coast and
  continue the normal smooth ramp without a low-speed hold;
- live stop/direction redirection during unfinished jog/stop handoffs;
- an edge-only ordinary-movement stop, including a short ownership lease for
  the main-before-render case, exact weapon/restored coefficient matching,
  setting/context/medical/reload/foreign-coefficient exclusions;
- existing brace history, uphill braking, input handling, slope state selection,
  ACE status/native stamina ownership and intermittent fatigue cleanup.

Downhill pace: 814 checks PASS. Default peak downhill targets rise about 1.97%
at 100 displayed lb and 3.29% at 150 lb; loads through 55 lb are unchanged.
Overall weight penalties, flat/uphill targets, sprint/ordinary pace floor and
extreme-slope bonus taper remain. The immutable slope model is unchanged.

Downhill trip: 4096 checks PASS. Default risk scales linearly with actual
horizontal speed above its minimum and continues rising above reference
speed, within the final probability bound. Per-second probability composes
across regular/irregular time intervals. Sustained high-speed history and
already-earned sprint qualification survive Shift release while still fast.
Unqualified sprint history cannot accrue sprint time after release. Stops,
invalid movement context and speed dropping below the relevant gate clear
qualification. Existing slope, weight, cooldown, immunity and recovery rules
remain; current diagnostics clear before invalid scope branches.

Animation graph: 6 tests PASS. Original 36 slope states/four action maps remain,
with four additional native-action idle targets. Stop interpolationSpeed is 8,
versus the native idle value 4 in the supplied gait32 RPT. Native animation
playback speed and root-motion data are inherited unchanged. Graph checks
verify blend routes and absence of forced switchMove resets/walk staging.

Heartbeat config: 3 tests PASS. All seven samples and pitches are unchanged.
Gain is 0.224403691, 20% of ACE's original db+1 amplitude, or 40% of alpha8.
The optional addon still patches only ACE Medical Feedback heartbeat sounds.
Compiled config entries are checked again during final packaging.

Preservation and mutation self-tests: PASS. All 25 historical RC4 block hashes
and original file reference hashes remain. Only exact authorized alpha9
movement and trip fragments/description edits are reversed before comparison.
Defaults, ranges, presets, base brace tuning, fatigue/visual ownership and
unrelated feature blocks remain protected. No GAIT aim/native-fatigue/recoil
writers were introduced.

PBO prefix layout: 4 tests PASS. Core prefix gait and heartbeat prefix
z\gait\addons\heartbeat remain disjoint. Both PBO SHA1 footers and all 16 raw
embedded scripts match final source. PowerShell build verification passes.
Alpha8 deployment cleanup/build-verification behavior is retained.

The ZIP contains full HEMTT source and ready_to_load/GAIT. VERIFY_READY.ps1
validates that standalone build against the bundled source. A SHA256 manifest
covers packaged source and build files; ZIP integrity is checked on creation.

Reproduce from the project root:
  hemtt build
  python tests/feature_preservation.py --self-test
  python tests/foundation_graph.py
  python tests/heartbeat_audio.py
  python tests/pbo_prefix_layout.py
  python tools/run_regressions.py --sqfvm /path/to/sqfvm --output /tmp/gait-tests
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/verify_build.ps1 -BuildPath .hemttout/build -SourceRoot .
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File VERIFY_READY.ps1

Limitations: half-duration stopping is the nominal blend-rate target, not a
measured guarantee that travel distance is exactly halved. Actual stopping
distance, cross-clip physical velocity continuity, animation appearance,
perceived loudness and post-processing appearance require Arma acceptance.
No measured clip-speed profiles or forced-velocity workaround are included.
Windows deployment/junction behavior remains a target-platform check;
PowerShell verification here ran under 7.4.7 on Linux.
