# GAIT

Ground-momentum ACE Integrated Traversal for Arma 3. GAIT adjusts movement for terrain, carried load, and sprint reserve. ACE supplies fatigue feedback.

The `dev/gait-foundation-1.8.0` branch provides the ACE-feedback-only build. See [build and deployment](README_HEMTT.md) for the one-time Git setup and the pull-and-deploy commands.
