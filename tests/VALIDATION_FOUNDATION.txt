GAIT 1.8.0-alpha10 validation

HEMTT 1.21.0 build: PASS, with BI Tools staging enabled.
Config version 1.8.0.10; 17 compiled SQF files; 2 PBOs.
Nonblocking style advisories remain. No Arma runtime was available.

All 20 actual-helper SQF-VM suites: PASS, zero diagnostics.
Recorded source hashes match the final source. Portable evidence is in
VALIDATION_RESULTS.json. The runner compiles each suite from current source.
Engine boundary mocks do not simulate animation rendering or physical travel.

New coverage:
- Lowered-pistol blend recognition: the six added cases fail against the
  alpha9 traversal helper and pass against alpha10. Ordinary lowered-pistol
  entries now connect to the existing pistol family without another brace.
- Actual release velocity affects finite duration at the same coefficient.
  Same-clip conversion, load-window ordering, monotonic decay, exact endpoints,
  early brace releases, malformed plans, partial retaps and 20/30/60/144 Hz
  sampling are exercised by the pure planner suite.
- The runtime suite executes the actual edge observer, finite sampler and
  native coefficient writer with engine context/clock/I/O boundaries mocked.
  Reversing main/render coefficient candidate order captures one plan, rejects
  stale scheduled coefficients and preserves the preexisting ownership value.
- A late sample applies the endpoint once; retaps return the remaining pace
  and a main-loop resume seed. A later release captures new velocity and pace.
- W-up, side/back/diagonal changes, weapon/family/clip changes, disabled settings,
  invalid context, expired/replaced requests and foreign coefficient writes
  cancel safely. Uphill braking takes priority and W-up cancels its clip hold.
- Source integration mutation checks verify observer-before-write/graph order,
  latest applied pace import, sole writer sampling, endpoint clearing and
  brace protection on release resume. Full engine scheduler timing remains
  an in-game check.

Existing suites retain brace history, uphill braking, input and stop/retap
policies, slope state selection, gear response, ACE status/native stamina
ownership, downhill pace/trip behavior and intermittent fatigue cleanup.

Limits: observed velocity and coefficient form a local current-clip sample,
not a calibrated native jog/walk target. Actual final cross-clip velocity,
animation appearance, stopping distance, perceived loudness and visual effects
require Arma acceptance. The short stop blend is not a measured guarantee of
halved travel distance. No forced-velocity workaround is included. Windows
deployment/junction behavior remains a target-platform check; PowerShell
verification here ran under 7.4.7 on Linux.
